# Root-bound terminal-closure fresh-cohort plan (THROWAWAY)

Question: does one immutable controller and execution plan preserve complete
process-tree resource authority for a fresh double-double refinement witness
cohort after a root disappears during a native inventory, without
reinterpreting, repairing, rerunning, mixing, or reusing any Issue 53
observation?

Review the whole plan and drive its in-memory review state with one command:

```text
python tools/prototypes/root_bound_terminal_plan_throwaway/tui.py
```

For a stable non-interactive snapshot:

```text
python tools/prototypes/root_bound_terminal_plan_throwaway/tui.py --snapshot all
```

The pure policy in `model.py` accepts only an ESRCH at an enumerated native
inventory coordinate for the launched root PID when the sole waiter closes the
same invocation handle from sample start through at most 1000 ms after the
adapter failure. Reap and complete process-tree cleanup must follow. The
incomplete inventory changes no successful-sample, error, or maximum-thread
count. Missing PID/phase, non-root loss, non-ESRCH, wrong handle/order, late or
missing terminal, missing reap, repeated reconciliation, incomplete cleanup,
and a counted incomplete sample all remain invalid. Candidate-owned exit,
timeout, and thread-grant failures remain nonpassing after valid controller
evidence.

The workflow `.github/workflows/freeze-root-bound-terminal-plan.yml` runs only
controller and synthetic-helper code. On every fixed lane it first closes the
inherited 277 ready-gated checks, then the Issue 55 pure controls. Linux
reproduces `linux-proc-process-tree/group-membership`; both macOS architectures
reproduce `macos-proc-process-tree/bsd-identity`; Windows runs the complete
policy and inherited controller checks because neither Issue 53 failure was a
Windows native coordinate. Every lane retains an atomic journal, and the
aggregation job rejects mixed commits, runs, controller bindings, workflow
identities, incomplete evidence, reruns, or any nonzero candidate/backend/
factor/solve/observation count.
